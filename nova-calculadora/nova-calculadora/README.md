# NOVA — Calculadora online

Calculadora responsiva com visual moderno, construída com HTML, CSS e JavaScript puro. Não precisa instalar dependências.

## Como executar no computador

1. Baixe e extraia o ZIP.
2. Abra a pasta `nova-calculadora`.
3. Dê dois cliques em `index.html`.
4. A calculadora abrirá no navegador.

## Recursos

- Operações básicas: soma, subtração, multiplicação e divisão.
- Porcentagem, inversão de sinal e apagar dígito.
- Histórico das últimas 8 contas; clique em uma conta para reutilizar o resultado.
- Suporte ao teclado: números, `+`, `-`, `*`, `/`, `%`, `Enter`, `Backspace` e `Esc`.
- Tema claro/escuro.
- Layout adaptável para celular e computador.
- Sem bibliotecas ou ferramentas de compilação.

## Publicar no repositório `ThiagoLeal25/Calculadora`

1. Extraia o ZIP no computador.
2. Abra o repositório: https://github.com/ThiagoLeal25/Calculadora
3. Se ele ainda estiver vazio, selecione **uploading an existing file** na tela inicial. Também é possível abrir https://github.com/ThiagoLeal25/Calculadora/upload/main.
4. Envie os quatro arquivos (`index.html`, `style.css`, `script.js` e `README.md`) para a raiz do repositório — envie os arquivos, não a pasta que os contém.
5. Clique em **Commit changes** para salvar os arquivos na branch `main`.
6. Abra **Settings → Pages**.
7. Em **Build and deployment**, selecione **Deploy from a branch**.
8. Selecione a branch `main` e a pasta `/(root)`, depois clique em **Save**.
9. Após a publicação, o endereço deverá ser `https://thiagoleal25.github.io/Calculadora/`. A primeira publicação pode demorar alguns minutos.

> A fonte DM Sans / Space Grotesk é carregada do Google Fonts quando há conexão com a internet. Se estiver offline, o site usa fontes alternativas.
